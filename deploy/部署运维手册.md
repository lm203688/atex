## 1. 三种部署方式

### A. Docker Compose（推荐，单台服务器）

```bash
cd deploy
cp .env.example .env          # 务必修改 ADMIN_TOKEN、CORS_ORIGINS
mkdir -p data certs
# 将证书放到 certs/fullchain.pem 与 certs/privkey.pem
docker compose up -d --build
```

- 应用镜像构建上下文为 `../app`（含 `requirements.txt`）。
- SQLite 持久化于 `./data/platform.db`（对应 `DB_PATH=/data/platform.db`）。
- Nginx 监听 80/443，静态 SPA + 反向代理 `/api`、`/ws`、`/docs`。
- 健康检查：`docker compose ps`（app 含 healthcheck `/api/health`）。

### B. systemd 裸机/VM（无 Docker）

```bash
sudo useradd -r -s /usr/sbin/nologin realcast
sudo mkdir -p /opt/realcast/{app,data,venv,backups,deploy}
sudo cp -r ../app/* /opt/realcast/app/
sudo cp .env.example /opt/realcast/deploy/.env   # 修改之
sudo python3 -m venv /opt/realcast/venv
sudo /opt/realcast/venv/bin/pip install -r /opt/realcast/app/requirements.txt
sudo cp realcast.service /etc/systemd/system/
sudo chown -R realcast:realcast /opt/realcast
sudo systemctl daemon-reload && sudo systemctl enable --now realcast
```

- Nginx 另装，配置复用 `nginx.conf`（把 `server app:8000` 改为 `server 127.0.0.1:8000`）。
- 单元已加 `NoNewPrivileges`/`ProtectSystem=strict`/`ReadWritePaths` 最小权限。

### C. 本地生产模式自查（开发机）

```bash
cd app
ADMIN_TOKEN=你的长随机串 CORS_ORIGINS=https://你的域名 \
DB_PATH=/abs/path/platform.db UVICORN_WORKERS=3 \
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --workers 3
```

## 2. 环境变量（`deploy/.env.example`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `ADMIN_TOKEN` | `dev-admin-token` | 运营后台令牌。**生产必须改长随机串（≥32 位）**。 |
| `CORS_ORIGINS` | `localhost,127.0.0.1` | 前端域名白名单，逗号分隔。 |
| `DB_PATH` | `./platform.db` | SQLite 路径，生产指向挂载卷（如 `/data/platform.db`）。 |
| `MAX_BODY_BYTES` | `1048576` | 请求体上限（1MB），超限 413。 |
| `UVICORN_WORKERS` | `3` | worker 数，SQLite+WAL 建议 2~4。 |
| `ORACLE_HTTP_ENDPOINT` | 空 | 外部权威源（结算自动对接），待接密钥。 |

## 3. Nginx（HTTPS + WebSocket + 限流 + 静态）

- 80→443 强制跳转；TLS 1.2/1.3。
- `/ws` 走 WebSocket 升级（`Connection: upgrade`），`proxy_read_timeout 3600s`。
- `/api` 走 `api_limit` 限流（20 r/s，burst 40）；全局 `global_limit` 60 r/s。
- 静态 SPA 由 `/usr/share/nginx/html`（挂载 `app/static`）直接托管，`/` 不缓存，资源缓存 7 天。
- 安全头：`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`；CSP 仅在静态页下发（避免与后端重复 AND 叠加）。**后端 `/api` 由应用自身下发 CSP**。
- **生产关闭文档**：注释 `location ~ ^/(docs|openapi.json)` 块以隐藏 Swagger。

## 4. 备份与监控

- **热备**：`backup.sh`（每日 cron），用 `sqlite3` 在线 `backup()`，保留 14 天。
  ```bash
  0 3 * * * /opt/realcast/deploy/backup.sh >> /opt/realcast/backups/cron.log 2>&1
  ```
- **健康检查**：`healthcheck.sh` 访问 `/api/health`（返回 `version`/`oracle_sources`/`counts`）。接入 Prometheus/node_exporter 或外部 uptime 监控。
- **日志**：uvicorn `--log-level warning`；nginx `access_log` 留存 ≥6 个月（等保）。

## 8. 故障排查

| 现象 | 排查 |
|---|---|
| 启动报 `unable to open database file` | `DB_PATH` 目录不存在或无写权限；确保目录已建且进程有写权。 |
| 端口被旧进程占用 | `fresh_start()` 已用 PowerShell 兜底杀；手动：`Get-NetTCPConnection -LocalPort 8000` 定位 PID 后 `Stop-Process`。 |
| CORS 预检失败 | 检查 `CORS_ORIGINS` 是否与前端 `Origin` 完全一致（含协议、端口）。 |
| 管理端点 401 | 请求头 `x-admin-token` 须等于 `ADMIN_TOKEN`。 |
| WebSocket 连不上 | Nginx `/ws` 需 `Upgrade`/`Connection` 头与 `proxy_read_timeout`；CSP 需含 `wss:`（已配）。 |
| SQLite 锁/写入慢 | 确认 `WAL`+`busy_timeout=30s` 已启用（默认）；高并发可上 Redis 缓存层（后续迭代）。 |
